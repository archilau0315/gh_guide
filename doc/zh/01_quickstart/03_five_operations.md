# 1.3 五个必会操作

> 这五个操作覆盖了 90% 的日常场景。每个配一个常见坑。

---

## 操作 1：放组件

**怎么做**：
1. 组件库面板（左）顶部的搜索框输入名字，比如 `Point XYZ`
2. 搜到后直接拖到画布上（或者双击也能放进去）
3. 也可以从工具栏左侧分组里展开，按分类浏览

**常见坑**：
- 同一组件拖多了容易找不到——点击画布空白处，鼠标滚轮快速缩放定位
- 组件分组折叠后看不到内容——点击分组标题左侧的小三角展开

**小技巧**：
- 画布上已经有一个组件，按 Ctrl+C / Ctrl+V 可以复制（或者拖的时候按住 Alt）
- 右键组件 → Duplicate Array 可以一键排 N 个（参数面板里设数量）

---

## 操作 2：连线

**怎么做**：
1. 组件**右侧**圆形是输出端口（带方向箭头），**左侧**方形是输入端口
2. 按住输出端口（鼠标悬停会高亮变色），拖到目标组件的输入端口上松开
3. 连好的线是灰色，运行正常后变绿色；报错的线变红色

**常见坑**：
- **接错方向**：从输入拖到输出也能连，但结果是反的——GH2 允许双向连线！要确认箭头方向
- **一个输入接多个输出**：GH2 支持多合并，比如同一个 `Curve` 输入可以接三条线。多条线会合并成数据树的多分支
- **端口接不上**：可能是组件运行时类型不匹配，或者端口已经被占了（GH2 的输入端口默认可以接多个，除非组件限制）

**小技巧**：
- 在线上双击 → 删除这条连线
- Ctrl + 点击输出端口 → 断开这个端口所有连线
- 鼠标悬停在端口上 → 弹出 Tooltip 显示类型、描述、当前值预览

---

## 操作 3：设参数

**怎么做**：
1. 选中组件（左键点一下）
2. 右侧参数面板会显示这个组件的所有输入端口
3. 直接在参数面板里输入数值 / 选择类型（Number Slider、Boolean Toggle、Colour Picker 等）
4. 或者把另一个组件的输出连进来（参数面板里的参数变成连线状态，灰色不可手动输入）

**常见坑**：
- **参数类型不匹配**：`Number` 参数不能接 `Point` 类型。GH2 会弹红色警告，不会静默转换
- **必填 vs 可选**：参数端口面板上标注 `(R)` 的是 required（必填），`(O)` 是 optional（可选）
- **数据 vs 参数**：连过来的值叫"数据输入"，手动设的叫"参数输入"。有数据输入时参数输入被忽略

**小技巧**：
- 右键参数面板上的端口 → Set Multiple Values → 可以一次给多个值
- Slider 组件的上下限可以在属性面板里改（双击 Slider 组件）

---

## 操作 4：看数据树

**怎么做**：
1. 运行后，每个输出端口都会产生数据
2. 鼠标悬停在端口上 → 弹出小窗口显示**数据树结构**：路径 + item 预览
3. 想看更详细的 → 拖一个 `Param Viewer` 组件（Params → Data → Param Viewer），把要查看的数据接进来
4. 或者用 `Data Path` 组件（Data → Tree → Data Path）：指定路径 `{0;2;4}` 取出某一枝

**数据树速查**：

```
路径表示法: {BranchIndex;ItemIndex;...}
  {0}     = 第 0 个分支（整体）
  {0;2}   = 第 0 个分支的第 2 个 item
  {0;2;4} = 嵌套数据：第 0 枝 → 第 2 子枝 → 第 4 个 item
```

| 操作 | 组件 | 用途 |
|---|---|---|
| 拍平 | `Flatten` | 去掉层级嵌套，所有 item 进一个分支 |
| 嫁接 | `Graft` | 在每一层 item 外面套一层分支（数据结构升级） |
| 简化 | `Simplify` | 去掉多余空层（数据结构降级） |
| 移位 | `Shift Paths` | 整体挪动路径索引 |
| 路径映射 | `Path Mapper` | 按规则重写路径（`{A;B;i}` → `{i;B;A}` 这种） |
| 查看 | `Param Viewer` / `Tree Viewer Topology` | 可视化数据树 |

**常见坑**：
- **数据树不匹配导致组件报错**：比如一个组件有 3 个输入端口，但它们的数据树分支数不一样（`none` 策略下会报错）
- **Flatten 丢了分支信息**：Flatten 后所有 item 进同一分支，原来的分组信息全没了——三思再拍

## 操作 5：Bake 到 Rhino

**怎么做**：
1. 在画布上选中要 Bake 的组件（可以多选，或者 Ctrl+A 全选）
2. **右键**选中的组件 → `Bake`（或右键 → Bake Selected）
3. 弹出 Bake 对话框：选目标图层、是否组、是否 Bake Metadata
4. 确认后，组件产生的几何体（点、曲线、曲面、网格）就进入 Rhino 场景了

**常见坑**：
- **Bake 会全部清空再重建**：同一组件反复 Bake 会产生重复几何体——Bake 前先清理旧 Bake 层（或用组件名前缀图层自动管理）
- **SubD Bake 成 Brep**：SubD 组件 Bake 时会自动转 Brep。要 Bake 成 SubD 实体，用 `SubD To Brep` 的反向组件 `Brep To SubD` 先转一下
- **Metadata 不会自动 Bake 到 Rhino Layer**：GH2 的 Metadata 是 GH 内部数据，Bake 到 Rhino 后丢失。如果要保留，用 `Meta Bake` 组件（会写 Rhino Layer 的 User Text）

**小技巧**：
- 右键组件 → Bake → 弹出对话框里**勾选 "Bake on Run"**：以后每次运行自动 Bake，省手动
- 用 `Bake` 组件（不是右键菜单）：程序化 Bake，可以设目标图层名、材质、是否组——适合自动化流程

## 五个操作串起来：画一条线的完整流程

```
1. 搜索 "Point XYZ"，拖两个到画布       ← 操作 1 放组件
2. 搜索 "Line" (Curve > Primitive > Line)，拖一个
3. Point1 的 Pt 输出 → Line 的 A 输入    ← 操作 2 连线
   Point2 的 Pt 输出 → Line 的 B 输入
4. 选中 Point XYZ 组件，右侧面板输入数值  ← 操作 3 设参数
   第一个: X=0, Y=0, Z=0
   第二个: X=10, Y=5, Z=0
5. 运行 F5 → Line 组件输出一条曲线      ← 操作 4 看数据
   悬停 Line 组件输出 → 看到一条 curve
6. 右键 Line 组件 → Bake               ← 操作 5 Bake
   确认图层 → 切回 Rhino 看到这条线
```

---

## 本章小结

五个必会操作的记忆点：
1. **放**：搜索框找，双击或拖
2. **连**：端口对端口，箭头方向对
3. **设**：参数面板改值，`(R)` 必填
4. **看**：悬停端口看数据树，路径 `{}` 记分支
5. **Bake**：右键组件，注意 SubD 和 Metadata 的处理
