# 1.1 装好就能用

> 读完这节，你应该能在 Rhino 9 里启动 GH2、认识界面四个区、放下第一个组件。

---

## 第一步：安装 Rhino 9

Rhino 9 自带 Grasshopper 2，不需要单独装。安装时勾上默认选项即可。

安装完成后，打开 Rhino 9，命令行输入 `Grasshopper`（或者按工具栏上的蝴蝶图标），回车——GH2 面板就出来了。

> **提示**：如果你同时装了 Rhino 8 或更早版本，GH1 和 GH2 可以并存。Rhino 8 用命令 `Grasshopper` 打开 GH1；Rhino 9 用同样的命令默认打开 GH2，想切回 GH1 用命令 `GrasshopperLegacy`。

---

## GH2 界面四区

GH2 面板（Floating Panel）从上到下、从左到右分成四个区域：

```
┌─────────────────────────────────────────────────┐
│  顶部工具栏（工具栏）                              │
│  ▶ 运行 / ⏸ 暂停 / ⏹ 停止 / 🐞 调试 / ▶▶ 一步   │
├─────────────────────────────────────────────────┤
│  左：组件库面板     │  右：参数（属性）面板          │
│  Curve / Surface    │  Name / Nickname / Category  │
│  Mesh / Maths ...   │  Exposure / Icon / Notes    │
│  搜索框在最顶上      │  （选中组件时显示）            │
├────────────────────┴────────────────────────────┤
│  中部：画布（Canvas）                              │
│  组件拖进来，用连线连接，运行后看数据流动。           │
├─────────────────────────────────────────────────┤
│  底部：通用数据栏（Output Bar）                      │
│  报错警告、运行时信息、Print 组件的输出。             │
└─────────────────────────────────────────────────┘
```

**记忆口诀**：左找组件、右看参数、中间接线、底部看报。

## 画布操作速查

| 操作 | 鼠标 / 快捷键 |
|---|---|
| 平移画布 | 中键拖动 / Alt + 左键拖动 |
| 缩放 | 滚轮 |
| 框选组件 | 左键框拖 |
| 多选 | Shift + 左键 |
| 移动组件 | 左键拖动 |
| 复制组件 | Ctrl + C / 拖动时按住 Alt |
| 删除 | Delete / Backspace |
| 连线 | 从输出端口拖到输入端口 |
| 断连线 | 在线上双击 / 选中后 Delete |
| 折叠/展开组件 | 点击组件左上角小三角 |
| 运行 | F5 / 顶部 ▶ |
| 暂停 | 顶部 ⏸ |
| 停止 | 顶部 ⏹ |
| 一键清屏 | Ctrl + Shift + N |

## 文件格式

| 格式 | 扩展名 | 用途 |
|---|---|---|
| GH2 定义文件 | `.ghz` | **Rhino 9 / GH2 专用**，二进制压缩 |
| GH1 定义文件 | `.gh` | Rhino 8 / GH1，文本 XML |
| Python 脚本组件 | `.py` | 脚本组件内嵌，可单独导出 |
| C# 插件 | `.gha` | 编译好的自定义组件 |
| 示例包 | `.zip` | 官方示例，解压后是 `.ghz` |

> **向后兼容**：GH2 不能直接打开 `.gh` 文件。官方提供了迁移工具 `GH1Interop` 组件，可以把 GH1 的部分组件拖进 GH2 画布自动转译，但不是所有 GH1 组件都能转。

## 本章小结

- **启动**：Rhino 9 命令行 → `Grasshopper`
- **界面四区**：组件库（左）· 参数面板（右）· 画布（中）· 输出栏（底）
- **基本操作**：拖动组件、端口连线、F5 运行、Delete 删
- **文件**：`.ghz` 是 GH2 原生格式，`.gh` 是 GH1 老格式
